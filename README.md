# タイマーアプリ

日本語対応・JST表示・カウントダウン機能付きのシンプルなWebタイマーです。

## 主な特徴
- シックなダークテーマ＆大人向けデザイン
- 日本標準時（JST）表示
- カウントダウンタイマー（プリセットは自分で自由に登録・削除できる）
- タイマー終了時に画面が黄色で点滅
- 「点滅を止める」ボタンで点滅解除＆音を鳴らす
- スマホ・PC両対応
- PWA対応（Windowsにインストール可能・タスクバーから起動）
- 常に最前面に浮かぶミニタイマー（Document Picture-in-Picture）
- オフラインでも動作

## 使い方
1. プリセットボタン、または任意の分・秒を入力し「セット」
2. 「スタート」でカウントダウン開始
3. タイマー終了時、画面が点滅し「点滅を止める」ボタンが表示されます
4. ボタンを押すと点滅が止まり、音が鳴ります

### プリセットを自分で設定する
よく使う時間は自由に登録できます（ブラウザに保存され、次回から復元されます）。

- **追加**: 分・秒を入力して **「＋ プリセットに追加」** を押す（最大10個・自動で昇順に並びます）
- **削除**: **「✏️ プリセットを編集」** を押すと各ボタンに `×` が出ます
- **戻す**: 編集中に表示される **「初期値に戻す」** で 1分 / 3分 / 5分 に戻ります

登録したプリセットはミニタイマーにもそのまま反映されます。

## Windows で使う

このアプリは PWA（Progressive Web App）化してあり、Windows にインストールして
デスクトップに常駐させたり、タスクバーから素早く起動したりできます。

### 前提
- **HTTPS で配信されていること**（GitHub Pages など）。`file://` では Service Worker が動かずインストールできません。

### 手順 1: アプリをインストールする
1. Microsoft Edge または Chrome で公開 URL（例: `https://junia2009.github.io/app_timer/`）を開く
2. アドレスバー右端の **インストール アイコン**（⊕）、または `…` メニュー →
   **アプリ** → **このサイトをアプリとしてインストール**
3. インストール後、スタートメニューに「My タイマー」が追加されます

### 手順 2: ミニタイマーを浮かべる
アプリ内の **「🪟 ミニタイマーを浮かべる」** ボタンを押すと、
**常に最前面に表示される小さなタイマー窓**が開きます。
他のウィンドウの上に浮いたままなので、作業しながら残り時間を見続けられます。

- 登録したプリセットはワンクリックでセット＆スタート
- `▶ 開始` / `⏸ 停止` / `↺ リセット` も小窓から操作可能
- 時間切れになると小窓も黄色く点滅し、`アラームを止める` ボタンが出ます
- 窓は自由にリサイズ・移動できます

Document Picture-in-Picture API を使っているため、**Edge / Chrome のデスクトップ版**で動作します。
非対応のブラウザではボタン自体が表示されません。

#### 本体ウィンドウはトップバーになります
ミニタイマーを開くと、本体の大きい画面は**画面上部の細いバー1本**になります。
「My タイマー」のロゴだけが光るシンプルな見た目で、**バーのどこをクリックしても
元の画面に戻ります**（ミニタイマーは開いたまま）。ミニタイマーを閉じても自動で戻ります。

インストール済み PWA として開いている場合は、ウィンドウ自体もバーの形に変形します。
高さはタイトルバーや枠の実寸を測って決めるので、中身が潰れません。

**本体が最大化されているとウィンドウは細くなりません。**
Chromium は最大化されたウィンドウの `resizeTo()` を無視するためです
（最大化を解除する JavaScript の API はありません）。
タイトルバーをダブルクリック、または `Win` + `↓` で最大化を解除すると、
アプリが検知して**自動で細くなります**（解除されるまで最大20秒間、待ち続けます）。
数秒待つとバーの右端に理由が表示されます。

#### なぜウィンドウが2つになるのか
最前面固定は、このやり方でしか実現できません。

- **ブラウザには最前面固定の API がありません。** 偽のログイン画面を最前面に居座らせる
  フィッシングを防ぐため、意図的に提供されていません。
- Web で最前面を取れる唯一の手段が Document Picture-in-Picture です。
  この API は**開いた元のページが生きていることが前提**で、本体ウィンドウを閉じると
  小窓も一緒に閉じます（実測で確認済み）。

そのため本体ウィンドウは残す必要があり、せめて邪魔にならないよう細いバーにしています。

### 手順 3: タスクバーにピン留めする
1. スタートメニューの「My タイマー」を右クリック → **タスクバーにピン留めする**
2. ピン留めしたアイコンを**右クリック**すると、**1分 / 3分 / 5分** のメニュー
   （ジャンプリスト）から直接タイマーを開始できます

### Windows ウィジェットボードについて
`manifest.json` には Windows ウィジェット用の定義（`widgets` / Adaptive Card テンプレート /
Service Worker のイベントハンドラ）を実装済みですが、**これだけではウィジェットボードの
「＋（ウィジェットの追加）」一覧には表示されません。**

Windows のウィジェットボードは、**MSIX パッケージのマニフェストに登録された widget provider**
（`uap3:AppExtension` の `Name="com.microsoft.windows.widgets"`）を持つアプリだけを列挙します。
ブラウザから「アプリとしてインストール」した PWA はパッケージ化されていないため、対象外です。

ウィジェットボードに載せたい場合は、[PWABuilder](https://www.pwabuilder.com/) で
この PWA の Windows パッケージ（MSIX）を生成し、サイドロードするか Microsoft Store に公開してください。
PWABuilder は `manifest.json` の `widgets` 定義を読み取ってパッケージに widget provider を登録するため、
**追加のコードは不要**です。

参考: [Display a PWA widget in the Windows Widgets Board](https://learn.microsoft.com/en-us/microsoft-edge/progressive-web-apps/how-to/widgets) /
[Widget provider package manifest XML format](https://learn.microsoft.com/en-us/windows/apps/develop/widgets/widget-provider-manifest)

### URL パラメータ
ミニタイマーやショートカット以外からも、URL で時間を指定して起動できます。

| パラメータ | 意味 | 例 |
| --- | --- | --- |
| `m` / `minutes` | 分 | `?m=3` |
| `s` / `seconds` | 秒 | `?s=30` |
| `autostart` | `1` で即スタート | `?m=5&autostart=1` |

例: `https://junia2009.github.io/app_timer/?m=1&s=30&autostart=1`

### 別のURLで公開する場合
`widget/timer-data.json` の `appUrl` / `iconUrl` を公開先の URL に書き換えてください。
（Service Worker が起動時に実際の配信 URL で上書きするため、インストール後は自動で補正されます）

### ファイル構成（PWA 関連）
```
manifest.json                 … PWA マニフェスト（アイコン・ショートカット・ウィジェット定義）
sw.js                         … Service Worker（オフライン対応 + ウィジェットのイベント処理）
icons/                        … インストール用アイコン（192 / 512 / maskable）
widget/timer-card.json        … ウィジェットの見た目（Adaptive Card テンプレート）
widget/timer-data.json        … テンプレートに流し込むデータ
widget/screenshot-widget.png  … ウィジェット追加画面に表示されるプレビュー
```

## 注意事項
- iPhone等のiOS端末では、音声再生は「点滅を止める」ボタンを押した時のみ鳴ります
- 音が鳴らない場合は、音量やファイルパス、ブラウザの設定をご確認ください
